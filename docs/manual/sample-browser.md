# Samples and sounds

The sidebar separates raw samples from reusable sounds, kits, instruments, and presets.

- Samples contains audio files for a sampler.
- Sounds contains saved sound setups for tracks.
- Kits contains saved drum-rack setups.
- Instruments contains sound generators and rack types.
- Presets contains settings for the selected instrument.

## Find and audition samples

Open Samples and use the search box or tag chips, such as kick, snare, clap, or a collection name. Factory and Yours separate shipped and personal collections. Expand folders when results appear as a tree.

Selecting a sample displays its preview. The headphone control enables automatic audition as you move through samples. Turn it off to browse silently. Previewing a file does not insert it into a pattern.

## Load a sampler

Drag a sample to **Drop sounds here** to make a new part. Drop it on an existing track to replace that track's sample or sound. Browser activation loads according to the selected-track context, so choose a destination first.

Confirm the waveform and sample name in the sampler panel, punch in a step, and play. Use Transpose for pitch, Velocity for accents, and the sampler's envelope and playback controls to shape the hit.

Loading a sample onto an instrument track can convert it to a sampler. Create a separate track if you want to keep the synth as well.

## Personal samples

1. Drag audio files or a folder from Finder onto the app window to open the import dialog.
2. Review the staged tree and the counts for ready files, files already in the library, and failures.
3. Add a batch tag for the whole import, such as a collection name. Type a tag and press Enter, or click a suggestion.
4. Select a folder to tag its whole subtree, or select one file to tag just that sample and edit its title.
5. Use the preview and headphone control to audition a selected file if needed.
6. Click Import to commit the ready files, or Cancel to abandon the staged import.

Batch tags apply to every imported sample; selection tags apply only to the selected file or folder subtree. Click a tag chip's x to remove it. These distinctions make it possible to give a whole collection one name while labeling its kick, snare, and hat folders separately.

Importing and loading are separate operations. First put files into the library, then choose where they should sound. For several percussion sounds, a [Drum rack](racks) is often easier than repeatedly replacing one sampler.

## Reusable sounds and kits

Use Sounds for reusable track sounds and Kits for drum-rack setups. A synth preset can be promoted to a Sound by dragging its preset item onto the Sounds tab. That makes it accessible without first selecting its instrument on a track.

Save a project version before replacing a sound or kit you want to keep. Loading another setup is a musical change, not merely a different browser view.
