# Factory Grooves

Read-only `.groove` files shipped in the bundle (docs/rack-groove-spec.md,
§Three tiers). `groove::library::list_groove_library` lists them first, then
the user's own saves (`user_data_root()/grooves`). Applying one to a drum rack
copies it into the project groove pool, so a project never depends on these
files.

The `mpc-swing-*` files are generated by `groove::mpc_swing_groove`; the test
`groove::tests::factory_mpc_swing_files_match_the_generator` keeps them in
sync, and `groove::tests::regenerate_factory_mpc_swing_files` (ignored; run
with `--run-ignored only`) rewrites them.
