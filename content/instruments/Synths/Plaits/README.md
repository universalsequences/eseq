# Plaits

A port of Mutable Instruments **Plaits**: all 24 synthesis models from both
original banks and the 1.2 firmware bank, the internal decay envelope that
sweeps FM / TIMBRE / MORPH, the low-pass gate, and the output limiters.
Ported from `plaits/dsp` in https://github.com/pichenettes/eurorack (commit
`f4cfa769`).

`dsp.lisp` and `data/` are generated by `tools/plaits/regenerate.sh` from the
sources in `tools/plaits` (shell, engines, table extractors); edit those, not
`dsp.lisp`. The data files are the module's lookup tables, its wavetables,
the LPC speech word banks, and the three banks of 32 DX7 patches used by the
6-op models, unpacked as the module does when it loads a patch.

## Models

UI order is the green bank, then the red bank, then the 1.2 bank:

0–7: VA, waveshaper, 2-op FM, formant/PD, harmonic, wavetable, chords, speech
8–15: swarm, filtered noise, particle, string, modal, bass drum, snare, hi-hat
16–23: VA + VCF, phase distortion, 6-op FM (3 banks), wave terrain, string machine, chiptune

## Fidelity

Every engine and the voice were checked sample by sample against the original
C++ compiled on the desktop (`tools/plaits/ref`).

- **Deterministic paths:** within 0.5% RMS error over the first 100 ms, and usually 0.0x%. This covers the oscillators, filters, envelopes, LPG, 6-op FM and the speech synths, in both LPG modes. Longer renders drift slowly, because phases accumulate in float instead of 32-bit integers.
- **Noise-driven models** (swarm, noise, particle, string and modal excitation, the noisy parts of the drums, unvoiced speech): matched sample by sample when both sides were fed the same noise, and statistically with real noise.
- **Chaotic patches:** a few 6-op FM patches with maximum feedback, and the bass drum at high self-FM and long decay, amplify float-rounding differences until the waveform diverges. Their level and spectrum still match.

Deliberate differences:

- **Triggers and LPG modes:** every note is a TRIG, and `lpg_mode` chooses what drives the low-pass gate. In **ping** the trigger alone strikes the gate, as when only TRIG is patched. In **gate** LEVEL follows gate × velocity, which also sets the accent.
- **No trigger delay:** the module's 1 ms trigger delay is not reproduced, because the host sends pitch and gate together.
- **Sample rate:** pitch follows the host sample rate. The module's other time constants keep their 48 kHz values.
- **Output:** float, with no 16-bit DAC rounding.
- **Bank 4:** the wavetable model's user bank plays the module's default user bank.

The string, particle and string-machine models keep their delay lines running
while another model is selected (silent), so each voice carries about 1% of a
core for them. Only the selected model's synthesis runs.
