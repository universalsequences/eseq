# Rings

A port of Mutable Instruments **Rings**: the six resonator models and the
Disastrous Peace string synth easter egg, with their reverb, chorus,
ensemble, formant filters and output limiter. Ported from `rings/dsp` in
https://github.com/pichenettes/eurorack (commit `f4cfa769`).

`dsp.lisp` and `data/` are generated by `tools/rings/regenerate.sh` from the
sources in `tools/rings`; edit those, not `dsp.lisp`. The data files are the
module's lookup tables. The chord, registration and formant tables are
parsed from the sources into `tools/rings/src/tables.lisp`, using the chord
set the firmware builds with (`BRYAN_CHORDS`).

## Models

`model` selects:

- **0 Modal:** 60 bandpass modes excited by a filtered impulse.
- **1 Sympathetic strings:** a plucked string and 7 strings tuned by STRUCTURE that ring in sympathy.
- **2 Inharmonic string:** one string with dispersion, curved bridge and noise.
- **3 FM voice:** two operators with feedback.
- **4 Sympathetic strings, quantized:** model 1 tuned to one of 11 chords.
- **5 String and reverb:** model 2 in stereo through the reverb.
- **6–11 Disastrous Peace:** an 8-note chord of divide-down string/organ voices. Each model is one of the module's six FX choices: formant, chorus, reverb, formant 2, ensemble and reverb 2.

## How it is played

Each note strums the internal exciter. This is the module with TRIG patched,
IN unpatched, and V/OCT unpatched so that FREQUENCY sets the pitch directly.

- **Polyphony:** each host voice runs the module at polyphony 1. The host's voices supply the overlapping decays that the module's 2- and 4-voice modes give.
- **Note-off:** notes ring past note-off until they decay. With DAMPING at its maximum, the strings sustain and Disastrous Peace drones.
- **Velocity:** scales the output.
- **Outputs:** ODD goes to the left channel and EVEN to the right. `spread` blends them towards the mono sum the module gives when only one output is patched.

## Fidelity

The voice was checked sample by sample against the original C++ `Part` and
`StringSynthPart`, compiled on the desktop (`tools/rings/ref`).

- **Every model:** within 0.1% RMS error over the first 100 ms (usually 0.00%), with the noise sources fed the same values on both sides. This holds for static settings, parameter and pitch sweeps and retriggers, and usually over the whole second rendered.
- **Noise:** with real noise, each pluck is a short random burst. Level, decay and spectrum fall within the reference's spread across random seeds. When both sides get the same noise streams (`RREF_NOISE`), the models match within 0.3%.
- **FM voice at maximum self-feedback and index:** chaotic. A 1/256-semitone change already decorrelates the module's own output, so only the level matches.
- **Sympathetic strings:** the position LFOs are cosine recurrences that are very sensitive to rounding. Over a second, the EVEN output drifts by a few percent from the reference.

Deliberate differences:

- **Sample rate:** pitch follows the host sample rate. So do the delay lengths and LFO rates of the reverb, chorus and ensemble, and the values the code derives from `kSampleRate`. Constants the module gives per sample or per block keep their 48 kHz values.
- **Output:** float, with no 16-bit DAC rounding. Controls are not low-pass filtered like the module's pots.
- **Effect memory:** the effects keep separate delay memory, where the module shares one buffer.
- **Model changes:** they do not reset the strings or the FM voice as the module does. Strings that leave the selected model are cleared instead.

The string delay loops and the effects run whether or not their model is
selected, because delay lines cannot be skipped like the scalar models. Each
voice therefore costs about 3.4% of a core even on the cheapest model.
