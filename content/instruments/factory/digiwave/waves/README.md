# Digiwave Wave Bank

`bank.json` holds 8 banks x 64 single-cycle waves x 512 samples (shape
`[512, 512]`, wave-major: `index = wave * 512 + sample`, wave index
`= bank * 64 + position`). Each oscillator picks a bank (`bank1`/`bank2`)
and sweeps its 64 waves with one modulatable `wave` param, as on the DDRW.

Banks: DDRW, AKWF 2, Chip, Video Game, Bit Reduced, Raw (raw + snippets),
Grain (distorted + granular), FM. Generated by `extract_bank.py`; `bank-manifest.txt` records the
source file behind every slot.

## Provenance

Source material: **AKWF-FREE** (Adventure Kid Waveforms), public domain /
CC0 1.0 Universal. Extracted from upstream commit
`8de90bf94376670947369e69de0af6b9fbd19286`.

- https://www.adventurekid.se/akrt/waveforms/adventure-kid-waveforms/
- https://github.com/KristofferKarlAxelEkstrand/AKWF-FREE

**Bank 0 (DDRW)** is the DPRO-DDRW v1 user bank copied verbatim from
`../../../monomachine/dpro/monomachine-dpro-ddrw-v1/waves/user-bank.json`,
so Digiwave on bank 0 sounds exactly like the original. That data is AKWF's
generic first bank, `AKWF/AKWF_0001` (64 waves), FFT-resampled 600 -> 512
and peak-normalized to 0.95 with DC kept; verified 2026-09-02 by
re-extracting and correlating (1.000 per wave). Note the
`AKWF--MonoMachine-SFX-60+` tree in the AKWF repo is NOT Monomachine-sampled
material: it is the same collection re-cut into 64-file folders for loading
into the Monomachine's SFX-60+ sampler card (byte-identical files). Bank 1 is
AKWF's generic bank 2 with the identical pipeline. Banks 2-7
pick 64 waves from one or two AKWF category folders, spread evenly across its
spectral-centroid range and ordered dark -> bright.

The AKWF-FREE clone (WAV files) is **not** part of this repo.

## Regenerate

```sh
python3 extract_bank.py /path/to/AKWF-FREE
```
